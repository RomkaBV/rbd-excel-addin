# РБД 3.0 — Excel Online Add-in

Нова архітектура без Excel-кабінетів у клітинках.

## Головний принцип

- персональна вкладка Excel має назву **за прізвищем працівника**: `Іванченко`, `Войцехівський`, `Ридванський` тощо;
- один і той самий Content Add-in вставляється на кожну персональну вкладку;
- `taskpane.js` читає назву активної вкладки, знаходить працівника в `tblRBDUsers2026` і бере його роль;
- роль з текстом `Керівник` отримує керівницькі права;
- виконавець бачить тільки свої заявки;
- усі зміни йдуть в одну центральну `tblRBDCommands2026`;
- `02_RBD_ProcessCommands` обробляє чергу та змінює `tblRBDRequests2026`;
- повна історія заявки показується в одному вікні як чат: коментарі, статуси, призначення, ERP і сповіщення.

## Файли GitHub

- `taskpane.html` — інтерфейс;
- `taskpane.js` — логіка надбудови;
- `manifest-content.xml` — Content Add-in для вставки на аркуш;
- `manifest.xml` — Task Pane manifest;
- `icon-32.png`, `icon-64.png`, `icon-80.png`;
- `office-scripts/01_RBD_Setup_New.ts` — одноразова підготовка книги;

- `office-scripts/03_RBD_RegisterNotificationResult.ts` — реєстрація результату відправки повідомлення.

## Порядок запуску

1. Зробити резервну копію Excel-файлу.
2. У Excel Online → Automate створити скрипт `01_RBD_Setup_New` і вставити код з файлу `office-scripts/01_RBD_Setup_New.ts`.
3. Запустити його один раз. Він **не очищає центральну базу заявок**, але очищає персональні вкладки працівників від старих Excel-кабінетів.
4. Створити скрипт `02_RBD_ProcessCommands` і вставити код з відповідного файлу.
5. Старий ALL-IN-ONE скрипт більше не запускати, бо він знову створить старі кабінети.
6. Завантажити файли проєкту в корінь GitHub-репозиторію `rbd-excel-addin`.
7. Перевірити GitHub Pages: `https://romkabv.github.io/rbd-excel-addin/taskpane.html`.
8. Завантажити `manifest-content.xml` в Excel та вставити Content Add-in на кожну персональну вкладку. Об'єкт можна скопіювати між аркушами.
9. Налаштувати Power Automate: раз на 1 хвилину запускати `02_RBD_ProcessCommands`. Concurrency = 1.

## Нова структура Excel

Основні технічні таблиці:

- `tblRBDRequests2026` — заявки;
- `tblRBDUsers2026` — працівники та ролі;
- `tblRBDStatuses2026` — статуси та SLA;
- `tblRBDTransitions2026` — дозволені переходи;
- `tblRBDAssignments2026` — призначення;
- `tblRBDCommands2026` — **єдина центральна черга**;
- `tblRBDTimeline2026` — **єдина нова хронологія заявки**;
- `tblRBDNotifications2026` — черга/стан відправки повідомлень;
- `tblRBDERPStage2026` — ERP staging;
- `tblRBDERPImports2026` — журнал ERP-імпортів;
- довідники міст, локацій, категорій, замовників і пріоритетів.

Старий `tblRBDEvents2026` та старі призначення не потрібно видаляти відразу: UI підтягує їх у єдину хронологію, щоб не втратити попередню історію.

## Хронологія як Telegram

При відкритті заявки користувач бачить одну стрічку:

- створення заявки;
- ERP-імпорт;
- призначення виконавця;
- зміни статусів;
- коментарі працівників;
- системні події;
- сповіщення та їх статус `Очікує / Надіслано / Помилка`.

Коментар вводиться прямо під стрічкою.

## ERP

ERP доступний тільки ролі з `Керівник`.

Файл `.xlsx`, `.xls` або `.csv`:

1. читається перший аркуш;
2. перевіряється ID ERP;
3. перевіряються довідники;
4. дублікати не створюються;
5. нові записи пишуться у staging і в `tblRBDCommands2026` як `CREATE`;
6. фактичну заявку створює `02_RBD_ProcessCommands`.

## Сповіщення

Процесор створює рядки в `tblRBDNotifications2026`. Для фактичної email-відправки потрібен Power Automate flow. Після успішної/невдалої відправки flow може запустити `03_RBD_RegisterNotificationResult`, і результат автоматично з'явиться в хронології заявки.
