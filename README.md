# РБД 2.0 — Excel Online Office Add-in

Ця надбудова — окрема вебпанель Excel (Office.js), **не Office Script**.

## Склад
- `taskpane.html` — світло-зелений інтерфейс.
- `taskpane.js` — Excel JavaScript API, робота з таблицями РБД 2.0.
- `manifest.xml` — маніфест Office Add-in.
- `icon-32.png`, `icon-64.png`, `icon-80.png` — піктограми.

## Підключення
1. Розмістіть `taskpane.html`, `taskpane.js` та зображення на одному HTTPS-хостингу.
2. Замініть **всі** `https://YOUR-HTTPS-DOMAIN.example` у `manifest.xml` на реальну HTTPS-адресу. Адреса в `SourceLocation` має відкривати саме `taskpane.html`.
3. У Excel Online скористайтеся завантаженням власної надбудови / маніфесту (якщо дозволено адміністратором Microsoft 365) або попросіть ІТ розгорнути її централізовано.
4. Відкрийте книгу РБД 2.0 з уже створеними Excel-таблицями.
5. Оберіть власний кабінет, заповніть форму та натисніть «Зберегти команду в Excel».
6. Після запису команди **окремо** запустіть загальний сценарій Office Scripts з вкладки «Автоматизація».

## Важливо
- Надбудова не створює та не змінює заявку безпосередньо: вона додає команди до персональних таблиць, щоб зберегти журнал і правила основного скрипту.
- Імена Excel-таблиць: `tblRBDUsers2026`, `tblRBDRequests2026`, `tblRBDStatuses2026`, `tblRBDCities2026`, `tblRBDLocations2026`, `tblRBDCategories2026`, `tblRBDCustomers2026`, `tblRBDPriorities2026`. Якщо Excel залишив автоматичні імена, змініть константу `C` у `taskpane.js` за реальною таблицею «Налаштування надбудови».
- Для однокористувацького пілота виведено селектор працівника; він **не є перевіркою особи**. Не можна вважати його безпечним для виробничої розділеної роботи. Потрібні Microsoft 365 SSO, правила доступу на сервері/SharePoint/Dataverse та централізований API.
- Створення локації через дію «Додати локацію» використовує поле «Опис / адреса» як адресу.
- Структура українських колонок відповідає останньому сценарію РБД.
- Для кількох виконавців з однаковими прізвищами персональні вкладки потребують унікальних назв.
