# РБД 3.1 — Excel Content Add-in + ERP ManageEngine

Ця версія побудована під нову логіку: персональна вкладка працівника = контейнер надбудови, усі зміни йдуть через одну центральну таблицю команд.

## Що змінилось у 3.1

- ERP-імпортер адаптований під реальні файли ManageEngine.
- Рядок заголовків визначається автоматично (у наданих файлах це 9-й рядок).
- Підтримується повний набір колонок ManageEngine; усі сирі поля зберігаються у `tblRBDERPStage2026`.
- Нові ID ERP створюють заявки.
- Повторне завантаження того самого ID ERP не дублює заявку: якщо дані змінились, створюється команда `ERP_SYNC`; якщо змін немає — рядок позначається `Без змін`.
- Статуси ManageEngine нормалізуються до статусів РБД.
- Пріоритети `2 Високий`, `3 Стандартний`, `4 Низький` автоматично переводяться у `Високий`, `Середній`, `Низький`.
- Виконавець зіставляється за прізвищем. Якщо працівника немає у довіднику РБД (наприклад, Тройченко Ігор), заявка все одно імпортується, а оригінальне ім'я зберігається у ERP-полях.
- Місто визначається з поля `Сайт`; повний `Сайт` зберігається як локація та як сире ERP-поле.
- Нові категорії, замовники та локації з ERP автоматично додаються у довідники під час обробки команд.

## Порядок оновлення існуючої книги

1. Замініть код Office Script `01_RBD_Setup_New.ts` і запустіть його **один раз**. Він додає відсутні колонки без очищення існуючих даних та не очищає персональні вкладки.
2. Замініть код Office Script `02_RBD_ProcessCommands.ts`.
3. `03_RBD_RegisterNotificationResult.ts` залиште/оновіть з цього пакета.
4. Завантажте на GitHub Pages нові `taskpane.html` та `taskpane.js`.
5. Відкрийте вкладку керівника → ERP → `Обрати файл`.
6. Перевірте попередній перегляд і натисніть `Імпортувати в РБД`.
7. Запустіть `02_RBD_ProcessCommands.ts` або ваш автоматичний Flow, який запускає цей процесор.

## Таблиці

- `tblRBDRequests2026` — центральний реєстр заявок.
- `tblRBDCommands2026` — єдина черга команд.
- `tblRBDTimeline2026` — єдина хронологія заявки.
- `tblRBDNotifications2026` — черга/журнал сповіщень.
- `tblRBDERPStage2026` — повний журнал сирих рядків ManageEngine + результат перевірки/мапінгу.
- `tblRBDERPImports2026` — журнал імпортів.

## Мапінг ManageEngine → РБД

- `Ідентифікатор запиту` → `ID ERP`
- `Час створення` → `Дата створення`
- `Технічний спеціаліст` → `Виконавець` (за прізвищем)
- `Сайт` → `Локація`, з нього визначається `Місто`
- `Тема` → `Тема заявки`
- `Статус запиту` + `Код закриття запиту` → `Статус`
- `Тип запита` → `Категорія`
- `Заявник` → `Замовник`
- `Пріоритет` → `Пріоритет`
- `Час останнього оновлення` → ERP-дата оновлення / дата оновлення заявки
- `Час завершення` → `Дата завершення`

Всі інші колонки ManageEngine також зберігаються у `ERP — вхідні` і не губляться.
