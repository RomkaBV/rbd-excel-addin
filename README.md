# РБД 2.0 — тест випадаючих довідників

Цей комплект використовує первинні файли `Книга (3).xlsx` та `1792001813790(1).xlsx`.

Реальні тестові довідники: 10 категорій, 30 міст, 9 працівників, 10 статусів, 5 фізичних сайтів ERP. Значення `Base Site` не використовується як фізична адреса.

Алгоритм: спочатку читає довідники з таблиць поточної книги, включно зі старими назвами `tbl_RBD_*`, `tbl_SLA`. Якщо таблиця відсутня або порожня, використовується тестовий список із `adapter.js`. Жодних заявок автоматично не створює і самі довідники Excel не перезаписує.

Завантажувати на той самий HTTPS-сервер усі файли; файл `test-seed.json` наведений для перевірки. Кнопки створення працюють через чергу, яка повинна існувати у книзі; сценарій її обробки залишається окремим.
