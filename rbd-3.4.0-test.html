Перевірити папку RBD_TEST_SANDBOX ↗


Що ми перевіряємо
Чи може окрема тестова сторінка з GitHub Pages передати команду до Apps Script. Скрипт генерує власний фіктивний файл у приватній тестовій папці (ліміт 10 за день).
Це не тест завантаження справжнього файлу з Excel, читання приватного Drive, запуску Outlook або авторизації працівника. Для них потрібен інший, захищений маршрут.
