# RBD → Google: схема інтеграції та безпечний запуск

## Поточний стан
- Excel створює нагадування у tblRBDReminders2026 та черзі tblRBDReminderQueue2026.
- Email береться з колонки «Електронна пошта» таблиці tblRBDUsers2026.
- Google Apps Script тестово надсилає нагадування Gmail за тригером.
- **Передавання з Excel до Google НЕ підключене.** Не видавати локальний запис у черзі за доставлений.

## Обов'язкова архітектура
1. Office add-in отримує достовірний корпоративний identity token через Microsoft 365/Entra SSO. Назва вкладки Excel та ПІБ у STATE.actor не є автентифікацією.
2. Backend перевіряє підпис, issuer, audience, expiration токена і права користувача щодо заявки.
3. Backend читає чергу або приймає її записи від add-in, перевіряє унікальний ID нагадування, ліміт частоти запитів і зберігає ідемпотентність. Відповідь API відокремлює accepted від sent.
4. Backend під своїми обліковими даними передає запис до приватної Google-таблиці (Google Sheets API) чи авторизованого backend worker. Секрети тільки на сервері.
5. Apps Script з тригером відправляє лише Pending після зазначеного часу. Для першого тесту жорстко встановити отримувача на тестову адресу, а початкового отримувача записати в окремій колонці для аудиту.
6. Після підтвердження приймання оновити стан черги в Excel. Після надсилання окремо підтягувати Sent/Failed.
7. Права на листи перевіряти окремо на сервері, не відкривати Google Drive «усім за посиланням».

## Необхідне для запуску
- Microsoft Entra application registration, client/application ID, tenant ID; затверджені SSO permissions; дозволений домен надбудови.
- Backend hosting із HTTPS, контрольованими секретами і журналом подій.
- Сервісний доступ backend до Google Sheet/Drive без надання доступу всім працівникам.
- Підтвердження політики компанії для зберігання листування на Google Drive.

## Тести готовності
- Створити нагадування для тестового користувача в Excel; у черзі статус «Очікує підключення Google».
- Після налаштування backend той же ID з'являється у Google рівно один раз.
- Повтор запиту не створює другого листа.
- Gmail надсилає лист лише тестовій адресі.
- Без валідного Microsoft токена сервер відмовляє з 401.
- Користувач без прав на заявку отримує 403.

## Заборонено
- Ушивати Google API key, bearer token або пароль у файли GitHub Pages.
- Виставляти Apps Script doPost як Anyone + Execute as me для службових даних.
- Вважати поле ПІБ або назву worksheet доказом особи.
