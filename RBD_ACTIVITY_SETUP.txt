RBD — Історія та примітки

Створіть в Excel окрему таблицю з назвою:
tbl_RBD_Activity

Колонки ОБОВ'ЯЗКОВО в такому порядку:
1. Activity ID
2. Request ID
3. Дата події
4. Автор
5. Тип
6. Текст
7. Дата нагадування
8. Статус нагадування
9. Дата виконання

Типи подій у поточній версії:
NOTE
REMINDER
STATUS

Статуси нагадування:
NEW
DONE

03_ProcessQueue змінювати не потрібно.
JS записує примітки/нагадування безпосередньо в tbl_RBD_Activity.
Зміна статусу записується в історію тільки після того, як 03_ProcessQueue реально підтвердив новий статус у tbl_RBD_Base або переніс заявку в архів.
